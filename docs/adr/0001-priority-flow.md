# ADR 0001: Bathroom-first journey scope split

- **Status:** Proposed
- **Date:** 2026-08-12
- **Decision:** Keep the product strictly bathroom-only with two explicit flows:
- Existing Bathroom and New Bathroom.
- Do not merge with kitchen/hvac/smart home paths in v1.

## Context

A mixed-domain product would dilute motion, trust, and guidance quality for this first flagship.

## Consequences

- Smaller, more coherent model
- Faster domain-specific UX depth
- Simpler recommendation and vision integration
