# Customer Journey

## Core journeys

### 1) Existing Bathroom (primary)

Goal: move from uncertainty to confident scope discovery.

1. Room entry
   - user enters dimensions quickly
   - immediate room placeholder render
2. Door placement
   - drag/drop placement on walls
3. Sequential wall capture
   - photo capture flow per wall with calm pacing
4. Computer vision pass
   - detect key fixtures and building elements
5. Confirmation and correction
   - user confirms or adjusts each detected item
6. Digital reconstruction
   - room model builds progressively
7. Scope cards
   - guided recommendations by urgency and impact
8. Package decision
   - curated recommendation set from trusted Feroterm categories
9. Handoff
   - structured summary for sales follow-up

### 2) New Bathroom

Goal: move from aspiration to realistic, budget-aware concept.

1. Style moodboarding
2. Material and lighting preference probing
3. Layout direction choice
4. Fixture and finish matching
5. Cost/risk visibility at each step
6. Final concept package with implementation-ready notes

## Emotional arc

- Curious → Comfortable → Understood → Confident → Excited → Ready

## Trust controls

- explicit confirmation at every automatic detection
- no hidden defaults
- reversible and transparent suggestion states
- clear explanation of "why this step is shown"
